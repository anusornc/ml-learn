Ensemble Learning & Gradient Boosting

การรวมพลังโมเดลพยากรณ์: Voting, Bagging, Random Forest, AdaBoost และ Gradient Boosting (XGBoost / LightGBM)

1 พลังของการรวมกลุ่ม (Wisdom of the Crowd) & Voting Classifiers

Ensemble Learning (การเรียนรู้แบบรวมกลุ่ม) ตั้งอยู่บนปรัชญาที่ว่า "กลุ่มของผู้ทำนายที่หลากหลาย มักจะให้คำตอบที่แม่นยำกว่าผู้เชี่ยวชาญเพียงคนเดียวเสมอ" หากเรารวมโมเดลที่เรียกว่า Weak Learners (ตัวเรียนรู้แบบอ่อน เช่น โมเดลที่ทายถูกเพียง 55-60%) เข้าด้วยกันเป็นจำนวนมาก ผลการลงคะแนนร่วมกันจะกลายเป็น Strong Learner ที่มีความแม่นยำสูงมาก

✦ Hard Voting (Majority Rule)

แต่ละโมเดลออกเสียงเลือกคลาสที่ตนเองทำนาย จากนั้นนับคะแนนเสียงข้างมาก (Majority Vote) คลาสที่ได้เสียงโหวตสูงสุดคือคำตอบสุดท้าย

$\hat{y} = \operatorname{mode}\{h_1(\mathbf{x}), h_2(\mathbf{x}), \dots, h_m(\mathbf{x})\}$

★ Soft Voting (Weighted Probabilities)

คำนวณค่าเฉลี่ยของความน่าจะเป็น (Probability) จากทุกโมเดล แล้วเลือกคลาสที่มีความน่าจะเป็นเฉลี่ยสูงสุด มักให้ความแม่นยำสูงกว่า Hard Voting เพราะโมเดลที่มั่นใจมากจะมีน้ำหนักมากกว่า

$\hat{y} = \underset{c}{\operatorname{argmax}} \, \frac{1}{m} \sum_{i=1}^{m} P_i(y=c|\mathbf{x})$

2 Bagging, Out-of-Bag (OOB) และ Random Forests

อีกหนึ่งแนวคิดคือการใช้อัลกอริทึมเดียวกัน แต่ฝึกสอนบน ชุดย่อยของข้อมูลที่สุ่มมาไม่เหมือนกัน:

  • Bagging (Bootstrap Aggregating): สุ่มข้อมูลตัวอย่างแบบ ใส่คืน (Sampling with replacement) ตัวอย่างหนึ่งอาจถูกเลือกซ้ำได้หลายครั้งในโมเดลเดียวกัน ช่วยลดค่าความแปรปรวน (Variance) ได้ดีมาก
  • Pasting: สุ่มข้อมูลตัวอย่างแบบ ไม่ใส่คืน (Sampling without replacement)
  • Out-of-Bag (OOB) Evaluation: ในกระบวนการ Bootstrap ทางสถิติจะมีข้อมูลประมาณ $36.8\%$ ($\approx 1/e$) ที่ไม่เคยถูกสุ่มไปฝึกในโมเดลนั้นเลย ข้อมูลส่วนนี้เรียกว่า OOB สามารถใช้เป็นชุดทดสอบ (Validation Set) ประเมินโมเดลได้ทันทีโดยไม่ต้องทำ Cross-Validation เพิ่มเติม

🌲 ป่าสุ่มตัดสินใจ (Random Forest)

Random Forest คือ Ensemble ของต้นไม้ตัดสินใจ (Decision Trees) ที่สร้างผ่าน Bagging โดยเพิ่มความชาญฉลาดอีกขั้น: ในแต่ละโหนดของการแตกกิ่ง อัลกอริทึมจะไม่หาฟีเจอร์ที่ดีที่สุดจากฟีเจอร์ทั้งหมด แต่จะ สุ่มเลือกซับเซตของฟีเจอร์ (มักใช้ $\sqrt{p}$ สำหรับ Classification) ทำให้ต้นไม้แต่ละต้นไม่มีความเกี่ยวเนื่องกัน (Decorrelated Trees) ส่งผลให้ลด Overfitting และแม่นยำสูงมาก

Feature Importance วัดความสำคัญของแต่ละตัวแปร โดยดูว่าฟีเจอร์นั้นช่วยลดค่า Impurity (Gini/Entropy) เฉลี่ยในทุกต้นไม้ไปมากเพียงใด
Extra-Trees (Extremely Randomized) สุ่มแม้กระทั่งจุด Threshold ในการตัดแบ่ง ทำให้เทรนได้เร็วกว่า Random Forest ปกติอย่างมาก

3 Boosting: AdaBoost และ Gradient Boosting (GBDT)

ต่างจาก Bagging ที่เทรนโมเดลแบบขนาน (Parallel) Boosting คือการเทรนโมเดลตามลำดับเวลา (Sequential) โดยให้โมเดลตัวใหม่ เรียนรู้และแก้ไขข้อผิดพลาดของโมเดลตัวก่อนหน้า

1. AdaBoost (Adaptive Boosting)

ปรับ น้ำหนักของตัวอย่างข้อมูล (Sample Weights): ตัวอย่างที่โมเดลก่อนหน้าทายผิด จะถูกเพิ่มน้ำหนักให้สูงขึ้น เพื่อบีบให้โมเดลตัวถัดไปต้องให้ความสำคัญกับตัวอย่างที่ยากเหล่านั้น

$$w_i^{(t+1)} = w_i^{(t)} \exp\left(-\alpha_t y_i h_t(\mathbf{x}_i)\right)$$

*เมื่อ $\alpha_t = \frac{1}{2} \ln\left(\frac{1 - \epsilon_t}{\epsilon_t}\right)$ คือน้ำหนักความน่าเชื่อถือของตัวทำนายที่ $t$*

2. Gradient Boosting (GBDT)

แทนที่จะปรับค่าน้ำหนักของข้อมูล Gradient Boosting จะให้โมเดลใหม่ ฟิตค่าความคลาดเคลื่อนส่วนตกค้าง (Residuals) ของโมเดลเดิมโดยตรง เทียบเท่ากับการทำ Gradient Descent ในพื้นที่ฟังก์ชัน!

$$y - \hat{y}_{(m-1)} \implies \text{ฝึก } h_m(\mathbf{x}) \text{ เพื่อทำนาย Residual}$$ $$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \, h_m(\mathbf{x})$$

*โดยที่ $\eta$ คือ Learning Rate (Shrinkage) ช่วยควบคุม Overfitting*

⚡ 3 เสาหลัก Gradient Boosting ยุคปัจจุบันในวงการอุตสาหกรรม

XGBoost

Extreme Gradient Boosting ใช้การประมาณอนุพันธ์อันดับ 2 (Hessian), มี L1/L2 Regularization ในตัว และตัดแต่งกิ่งแบบ Exact Greedy

LightGBM

จาก Microsoft ใช้ Histogram-based binning และการแตกกิ่งแบบ Leaf-wise (Best-first) เร็วขึ้นหลายเท่าและประหยัดแรมมหาศาล

CatBoost

จาก Yandex โดดเด่นเป็นเลิศในการจัดการข้อมูลตัวแปรกลุ่ม (Categorical Features) โดยไม่ต้องทำ One-Hot Encoding ล่วงหน้า
