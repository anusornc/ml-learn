# Lab 04: Training Linear Models (การฝึกฝนโมเดลเชิงเส้น)

โฟลเดอร์นี้รวบรวมไฟล์สคริปต์ Python สำหรับบทเรียนที่ 3, 4 และ 6 ของหลักสูตร Machine Learning เพื่อศึกษาการทำงานของ Linear Regression, Gradient Descent, Polynomial Regression, และ Logistic/Softmax Regression

---

## 📁 รายการไฟล์ภายในโฟลเดอร์

1. **`04_training_linear_models.py`**:
   - สคริปต์ภาษาอังกฤษแบบเต็ม แปลงมาจาก Notebook `04_training_linear_models.ipynb`
   - ครอบคลุม: Normal Equation, Batch/Stochastic/Mini-batch GD, Polynomial Regression, Learning Curves, Regularized Models (Ridge, Lasso, ElasticNet), และ Logistic/Softmax Regression
2. **`04_training_linear_models_th.py`**:
   - สคริปต์ฉบับภาษาไทย พร้อมคำอธิบายและตัวอย่างประกอบ

---

## 💻 วิธีการรันสคริปต์

```bash
# รันไฟล์ภาษาอังกฤษ
python3 lab-04-linear-models/04_training_linear_models.py

# หรือรันไฟล์ฉบับคำอธิบายภาษาไทย
python3 lab-04-linear-models/04_training_linear_models_th.py
```
