Support Vector Machines (SVM) & Kernel Trick

เส้นแบ่งขอบกว้างที่สุด (Max Margin), ซอฟต์มาร์จิน, การแปลงมิติด้วยฟังก์ชันเคอร์เนล (RBF) และ Support Vector Regression

1 ขอบเขตแบ่งกลุ่มที่กว้างที่สุด (Maximum Margin) & Support Vectors

สำหรับข้อมูลที่สามารถแบ่งแยกเป็นสองกลุ่มได้ด้วยเส้นตรง (Linearly Separable) จะมีเส้นแบ่ง (Decision Boundary) ที่เป็นไปได้จำนวนนับไม่ถ้วน แต่ Support Vector Machine (SVM) จะเลือกเส้นตรงเพียงเส้นเดียวที่อยู่ "ห่างจากจุดข้อมูลของทั้งสองฝั่งมากที่สุด" ซึ่งเรียกว่า Maximum Margin Hyperplane

📐 พื้นฐานคณิตศาสตร์ของเส้นแบ่งและมาร์จิน (Margin)

กำหนดไฮเปอร์เพลนด้วยสมการ: $\mathbf{w}^T\mathbf{x} + b = 0$

ขอบเขตบนและล่าง (Street Margins)

$\mathbf{w}^T\mathbf{x} + b \ge +1 \quad \text{สำหรับคลาส } +1$

$\mathbf{w}^T\mathbf{x} + b \le -1 \quad \text{สำหรับคลาส } -1$

ความกว้างของถนน (Margin Width)

$$\text{Margin} = \frac{2}{\|\mathbf{w}\|}$$

การทำให้ Margin กว้างที่สุด เท่ากับ การลดขนาด $\|\mathbf{w}\|$ ให้เหลือน้อยที่สุด ($\min \frac{1}{2}\|\mathbf{w}\|^2$)

Support Vectors: คือจุดข้อมูลเพียงไม่กี่จุดที่นอนอยู่บนเส้นขอบถนนพอดี ($\mathbf{w}^T\mathbf{x} + b = \pm 1$) จุดเหล่านี้เป็นผู้กำหนดตำแหน่งและทิศทางของเส้นแบ่ง หากเราลบจุดข้อมูลอื่น ๆ ที่อยู่นอกถนนทิ้งไป โมเดลจะยังคงได้เส้นแบ่งเดิมทุกประการ!

2 ซอฟต์มาร์จิน (Soft Margin) และไฮเปอร์พารามิเตอร์ $C$

ในโลกความเป็นจริง ข้อมูลมักมีสัญญาณรบกวน (Noise) หรือจุด Outliers ที่ทำให้ไม่สามารถขีดเส้นตรงแบ่งแยกได้อย่างสมบูรณ์แบบ (Hard Margin จะล้มเหลวทันที) เราจึงต้องใช้ Soft Margin Classification ซึ่งยอมให้มีจุดข้อมูลบางจุดล่วงล้ำเข้ามาในมาร์จินหรืออยู่ผิดฝั่งได้ โดยวัดความผิดพลาดด้วยตัวแปรผ่อนปรน (Slack Variable: $\xi_i \ge 0$)

สมการเป้าหมายแบบผ่อนปรน (Soft Margin Objective):

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^{m} \xi_i \quad \text{ภายใต้เงื่อนไข } y_i(\mathbf{w}^T\mathbf{x}_i + b) \ge 1 - \xi_i$$
ค่า $C$ สูง (Strict / Low Regularization)

โมเดลจะลงโทษจุดที่ผิดพลาดอย่างหนัก ทำให้ถนนมาร์จินแคบ ขอบเขตเข้มงวด ลด Bias แต่เสี่ยงต่อการเกิด Overfitting

ค่า $C$ ต่ำ (Tolerant / High Regularization)

โมเดลยอมให้จุดล่วงล้ำเข้ามาในมาร์จินได้มากขึ้น ทำให้ถนนกว้างขึ้น ทนทานต่อ Outlier แต่หากต่ำเกินไปจะเกิด Underfitting

3 กลวิธีเคอร์เนล (The Kernel Trick) & ฟังก์ชัน RBF

เมื่อข้อมูลไม่สามารถแบ่งแยกด้วยเส้นตรงได้ในมิติเดิม ทางออกคลาสสิกคือการแปลงข้อมูลไปยังมิติที่สูงขึ้น (Feature Mapping: $\phi(\mathbf{x})$) เช่น จาก 2 มิติ สู่ 3 มิติ เพื่อให้สามารถขีดระนาบตรงตัดแบ่งได้ แต่การแปลงมิติโดยตรงต้องใช้ต้นทุนการคำนวณและหน่วยความจำมหาศาล

✨ ความมหัศจรรย์ของ The Kernel Trick

กลวิธีเคอร์เนล (Kernel Trick) อาศัยทฤษฎีบทของเมอร์เซอร์ (Mercer's Theorem) ซึ่งพิสูจน์ว่า เราสามารถคำนวณผลคูณจุด (Dot Product) ในมิติที่สูงมาก (หรือแม้กระทั่งมิติอนันต์!) ได้โดยตรงจากพิกัดในมิติต่ำเดิม: $K(\mathbf{a}, \mathbf{b}) = \phi(\mathbf{a})^T \phi(\mathbf{b})$ โดย ไม่ต้องแปลงพิกัด $\phi(\mathbf{x})$ จริงเลยแม้แต่น้อย!

1. Polynomial Kernel
$K(\mathbf{a}, \mathbf{b}) = (\gamma \mathbf{a}^T\mathbf{b} + r)^d$

สร้างความสัมพันธ์แบบพหุนาม ดีสำหรับข้อมูลที่มีปฏิสัมพันธ์แบบเชิงคูณ

2. Gaussian RBF (Radial Basis Function)
$K(\mathbf{a}, \mathbf{b}) = \exp(-\gamma \|\mathbf{a} - \mathbf{b}\|^2)$

เคอร์เนลยอดนิยมอันดับ 1 เทียบเท่าการแมปข้อมูลไปยัง มิติที่เป็นอนันต์ ($\infty$)

💡 บทบาทของไฮเปอร์พารามิเตอร์ $\gamma$ (Gamma): ทำหน้าที่กำหนดความกว้างของระฆังคว่ำแบบเกาส์เซียน หาก $\gamma$ สูง จุดแต่ละจุดจะมีรัศมีอิทธิพลแคบ ขอบเขตจะหยักโค้งรอบจุดข้อมูลอย่างมาก (เสี่ยง Overfitting) แต่หาก $\gamma$ ต่ำ รัศมีจะกว้าง ขอบเขตจะเรียบแบนขึ้น
