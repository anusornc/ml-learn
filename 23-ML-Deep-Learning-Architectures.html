สถาปัตยกรรม Deep Learning ยุคใหม่

เจาะลึกโครงข่ายประสาทสังเคราะห์สำหรับการมองเห็น (CNNs), ปฏิวัติวงการ AI ด้วยกลไกความใส่ใจของ Transformers (Self-Attention) และเทคนิค Transfer Learning สู่โมเดลรากฐาน (Foundation Models)

1 Convolutional Neural Networks (CNNs) และการมองเห็นของคอมพิวเตอร์

ในอดีต การใช้ Multi-Layer Perceptron (Dense / Fully Connected Layer) ประมวลผลภาพถ่ายความละเอียดสูง เช่น ภาพ $1000 \times 1000$ พิกเซล 3 ช่องสี จะมีน้ำหนักเชื่อมต่อมหาศาลถึง $3 \times 10^6$ ค่าน้ำหนักต่อหนึ่งนิวรอน ซึ่งทำให้เกิดปัญหา Parameter Explosion และ Overfitting อย่างรุนแรง นอกจากนี้ Dense Layer ยังสูญเสียมิติเชิงพื้นที่ (Spatial Invariance) เพราะต้องคลี่ภาพ 2D ให้เป็นเวกเตอร์ 1D

CNN (Convolutional Neural Network) แก้ปัญหานี้ด้วยหลักการสำคัญ 3 ประการ:

1. Local Receptive Fields

นิวรอนแต่ละตัวจะไม่มองภาพทั้งบาน แต่จะเชื่อมต่อเฉพาะบริเวณเล็กๆ (เช่น $3 \times 3$ หรือ $5 \times 5$) ช่วยจับโครงสร้างเฉพาะที่ เช่น ขอบ, เส้น, มุม

2. Shared Weights (Weight Sharing)

ชุดตัวกรอง (Filter/Kernel) เดียวกันจะถูกเลื่อนสแกนทั่วทั้งภาพ ทำให้น้ำหนักมีจำนวนน้อยมาก และเรียนรู้ฟีเจอร์ได้โดยไม่ขึ้นกับตำแหน่งของวัตถุ (Translation Invariance)

3. Pooling & Downsampling

การย่อขนาดข้อมูลเชิงพื้นที่ด้วย Max Pooling หรือ Average Pooling เพื่อลดมิติ ลดภาระการประมวลผล และเพิ่มความทนทานต่อการขยับ/เอียงของภาพ

สูตรคำนวณมิติขนาดผลลัพธ์ (Feature Map Output Dimension)

หากภาพอินพุตมีขนาดกว้าง $W$, ตัวกรองขนาด $K$, การเพิ่มขอบ (Padding) เท่ากับ $P$, และระยะก้าว (Stride) เท่ากับ $S$:

$$O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$$
Valid Padding ($P = 0$): ไม่เติมศูนย์รอบขอบภาพ ขนาดของ Feature Map จะเล็กลงเรื่อยๆ หลังผ่านแต่ละเลเยอร์
Same Padding: เติมศูนย์รอบภาพจนทำให้ขนาด Feature Map ขาออกเท่ากับขาเข้าเดิม (เมื่อ $S = 1$) โดย $P = \frac{K - 1}{2}$

วิวัฒนาการสถาปัตยกรรม CNN คลาสสิก

VGG-16 / 19

เสนอแนวคิดว่าการใช้ Kernel ขนาดเล็ก $3 \times 3$ ซ้อนกัน 2 ชั้น มี Receptive Field เทียบเท่า Kernel $5 \times 5$ แต่ใช้พารามิเตอร์น้อยกว่าและเพิ่ม Non-linearity (ReLU) ได้ 2 รอบ

ResNet (He et al., 2015)

แก้ปัญหา Vanishing / Exploding Gradient ในโครงข่ายที่ลึกเป็นร้อยเลเยอร์ด้วย Residual Connection (Skip Connection): $$\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$$ ทำให้ Gradient สามารถไหลย้อนกลับผ่านทางลัดได้อย่างราบรื่นโดยไม่หายไป

3 ปฏิวัติวงการ AI ด้วย Transformers และกลไก Self-Attention

ก่อนปี 2017 โครงข่ายแบบลำดับอย่าง RNN และ LSTM ครองวงการประมวลผลภาษาธรรมชาติ (NLP) ทว่ามีจุดอ่อนสำคัญคือ การประมวลผลต้องทำทีละคำตามลำดับเวลา (Sequential Bottleneck) ทำให้ไม่สามารถใช้ประโยชน์จากการคำนวณแบบขนานบน GPU ได้อย่างเต็มที่ และยังพบปัญหาลืมบริบทที่อยู่ห่างไกล (Long-term Dependency Problem)

งานวิจัยประวัติศาสตร์ "Attention Is All You Need" (Vaswani et al., 2017) เสนอสถาปัตยกรรม Transformer ที่ตัดกลไก Recurrence ออกทั้งหมด และพึ่งพาเพียง Self-Attention ทำให้โมเดลสามารถมองเห็นทุกคำในประโยคพร้อมกันได้ทันทีแบบขนาน

สมการ Scaled Dot-Product Attention

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
Query ($Q$)

คำถามหรือสิ่งที่โทเค็นปัจจุบันกำลังมองหาในข้อความ (สิ่งที่ฉันต้องการ)

Key ($K$)

ป้ายชื่อหรือกุญแจของแต่ละโทเค็น เพื่อเทียบความสอดคล้องกับ $Q$ ด้วย Dot Product

Value ($V$)

เนื้อหาข้อมูลจริงของโทเค็น ที่จะถูกถ่วงน้ำหนักตามคะแนนความใส่ใจ (Attention Weight)

ทำไมต้องหารด้วย $\sqrt{d_k}$? เมื่อมิติของเวกเตอร์ $d_k$ มีค่าสูง ผลคูณ Dot Product $QK^T$ จะมีค่าขนาดใหญ่มาก ส่งผลให้ฟังก์ชัน $\text{softmax}$ เข้าสู่บริเวณที่ความชันเกือบเป็นศูนย์ (Vanishing Gradient) การปรับสเกลด้วย $\frac{1}{\sqrt{d_k}}$ จะช่วยให้การคำนวณเสถียร
Multi-Head Attention

แทนที่จะคำนวณ Attention เพียงชุดเดียว โมเดลจะแตก $Q, K, V$ ออกเป็น $h$ หัวย่อย (เช่น 8 หรือ 16 หัว) เพื่อเรียนรู้ความสัมพันธ์ในแง่มุมที่ต่างกัน เช่น หัวหนึ่งดูความสัมพันธ์ทางไวยากรณ์ อีกหัวหนึ่งดูความสัมพันธ์ของคำสรรพนามกับคำนาม

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h)W^O$$
Vision Transformer (ViT)

การนำ Transformer มาใช้กับรูปภาพ โดยหั่นภาพออกเป็นชิ้นสี่เหลี่ยมเล็กๆ (Patches ขนาด $16 \times 16$) แล้วมองแต่ละชิ้นเสมือนเป็น "คำหนึ่งคำ" (Tokens) ป้อนเข้าสู่ Transformer Encoder ทำให้ทำลายสถิติโมเดลบนชุดข้อมูลภาพขนาดใหญ่

4 การถ่ายทอดการเรียนรู้ (Transfer Learning) และโมเดลรากฐาน (Foundation Models)

ในอุตสาหกรรมยุคปัจจุบัน การฝึกโมเดล Deep Learning ขนาดยักษ์ตั้งแต่ศูนย์ (Training from scratch) ต้องใช้ค่าใช้จ่ายและพลังงานคอมพิวเตอร์มหาศาล ทางออกที่เป็นมาตรฐานวิศวกรรมคือ Transfer Learning: การนำโมเดลที่ผ่านการเทรนบนชุดข้อมูลมหึมา (Pre-trained Model) มาปรับจูน (Fine-tuning) กับงานเฉพาะทางของเรา

1. Feature Extraction (แช่แข็งโครงข่าย) ข้อมูลน้อย

ทำการ Freeze ทุกเลเยอร์ใน Backbone (ไม่ให้อัปเดตค่าน้ำหนัก) แล้วสร้างเลเยอร์ลักษณนาม (Classification Head) ใหม่มาต่อท้าย ฝึกเฉพาะเลเยอร์ใหม่เท่านั้น

  • ใช้พลังประมวลผลต่ำมาก ฝึกเสร็จรวดเร็ว
  • ป้องกันการ Overfitting เมื่อมีข้อมูลงานใหม่เพียงไม่กี่ร้อยภาพ
2. Fine-Tuning (ปลดล็อกเพื่อปรับจูน) ข้อมูลปานกลาง-มาก

ปลดล็อก (Unfreeze) เลเยอร์ส่วนบนของ Backbone บางส่วน หรือทั้งหมด แล้วฝึกต่อด้วย อัตราการเรียนรู้ที่ต่ำมาก (Very Low Learning Rate เช่น $10^{-5}$)

  • ระวัง Catastrophic Forgetting (การลืมฟีเจอร์พื้นฐานเดิม)
  • ให้ความแม่นยำสูงที่สุดเมื่อชุดข้อมูลมีความจำเพาะทางโดเมนสูง
ตัวอย่าง Transfer Learning ด้วย Hugging Face & PyTorch Python 
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments

# 1. โหลด Pre-trained Model และ Tokenizer
model_name = "bert-base-multilingual-cased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=3)

# 2. ตั้งค่า Hyperparameters สำหรับ Fine-tuning ด้วย Learning Rate ต่ำ
training_args = TrainingArguments(
    output_dir="./results",
    learning_rate=2e-5,        # อัตราการเรียนรู้ต่ำเพื่อถนอมน้ำหนักเดิม
    per_device_train_batch_size=16,
    num_train_epochs=3,
    weight_decay=0.01,
)
